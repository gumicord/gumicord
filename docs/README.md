# Gumicord docs

Developer guides for the Gumicord monorepo. Available in [English](en/README.md)
and [Japanese](ja/README.md).

- [English docs](en/README.md) — architecture, crates, theme guide, plugin guide
- [Japanese docs](ja/README.md) — same content in Japanese

Conventions:

- `spec/` is the single source of truth. These docs are guides; when they
  disagree with `spec/`, the spec wins.
- Code is English, specs are Japanese (`spec/README.md`, rule 6). The English
  pages below follow the code; the Japanese pages follow the spec.
